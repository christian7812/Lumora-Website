### Connecting to the backend

The Admin app uses `https://lumora-server-kwev.onrender.com/api` by default in
development and production. To use a local backend instead, set
`VITE_API_URL=http://localhost:8000/api` in an `Admin/.env.local` file.

When deploying the Admin app, add its exact public origin to the backend's
`CORS_ORIGINS` environment variable (alongside any existing store origins) so
cross-origin API requests and sign-in cookies are accepted. Set
`VITE_API_URL` in the Admin hosting environment only if the backend URL differs
from the default.

### Running the development server.

```bash
    npm run dev
```

### Building for production.

```bash
    npm run build
```

### Running the production server.

```bash
    npm run start
```
